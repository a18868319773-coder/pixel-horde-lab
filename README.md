# 尸潮禁区 · Pixel Horde

像素风 3D 生存战斗网页 Demo。此快照保留当前图像主菜单、动态背景、悬停发光与裁切修复。

## 本地预览

在项目根目录运行 `python3 -m http.server 8000`，访问 http://localhost:8000。无需构建。

## GitHub Pages

仓库 Settings → Pages → Build and deployment → Deploy from a branch，选择 main 分支、根目录 / (root)，保存。等待 Pages 部署完成后使用其生成的地址。

## 操作

- WASD / 方向键：移动
- 鼠标右键拖动 / 自由鼠标模式：转动视角
- R：技能；Space：跳跃；Shift：闪避
- 靠近树木或石头长按 F：采集
- M：全局地图；P / Esc：暂停

## 当前范围

标准出击、生存挑战、本地 AI 队友演练、任务领奖、资源兑换、研究建造、图鉴和成就。合作模式为 AI 演练，排行榜与社区笔记为本机数据。存档保存在浏览器；不同域名的存档互不共享。
